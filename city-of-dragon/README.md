# City of Dragon: Epic Battle
Kolektor naga · auto-battle tim vs tim · bangun kota. Godot 4, pixel art, Android + PC landscape.

| Berkas | Isi |
|---|---|
| `docs/art-direction-brief.md` | Aturan gaya, ukuran sprite, penamaan, folder |
| `docs/riset-aset.md` | Sumber aset gratis/murah + lisensi |
| `docs/pratinjau/` | Lembar pratinjau naga, telur, UI/kota/latar/efek |
| `assets/asset-manifest.json` | Pack terpasang, lisensi, kebutuhan yang masih kurang |
| `assets/CREDITS.md` | Kredit pembuat aset |
| `assets/dragons/roster.json` | Daftar naga + usulan elemen |
