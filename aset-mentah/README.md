# Aset Mentah
Berkas asli yang diunduh dari OpenGameArt.org pada 2026-11-11, belum diubah. Dipakai bersama oleh semua game di repo ini.

- Semua pack berlisensi **CC0 1.0** (domain publik): boleh dipakai komersial, diubah, dan dibagikan ulang tanpa kredit.
- `sunset-temple-tiles` dirilis ganda CC-BY 3.0 / CC0; di sini dipakai sebagai CC0.
- `dragon-fully-animated` berukuran 133 MB dan dipecah jadi 2 bagian (batas GitHub 100 MB per berkas). Gabungkan: `cat "Dragon - Fully Animated.zip.part1" "Dragon - Fully Animated.zip.part2" > "Dragon - Fully Animated.zip"`.
- Kolom "Dipakai" = sebagian isinya sudah disalin ke `hatch-and-fuse/assets/`.
